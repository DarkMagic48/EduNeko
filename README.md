# EduNeko

Aplicación web educativa orientada a estudiantes de secundaria.

## Tecnologías

### Frontend
- Angular
- TypeScript
- Node.js / npm

### Backend
- Java 21
- Spring Boot
- Maven

### Base de datos
- PostgreSQL

## Requisitos

- Java JDK 21
- Maven 3.9.x
- Node.js
- npm
- Angular CLI
- PostgreSQL
- Git
- Visual Studio Code

## Ejecutar backend

cd backend
mvn spring-boot:run

Backend:
http://localhost:8080

Health:
http://localhost:8080/api/health

## Ejecutar frontend

cd frontend
npm install
npm start

Frontend:
http://localhost:4200
